# A first project in Folio

## Compare options and deliver a brief / 比较方案并交付简报

**English:** Choose **New project → Comparison & decision brief**, or use **Explore a complete comparison sample**. Define your objective and constraints, name the options and criteria, then link sources in each column header. Open a cell to record a fact, judgment or unanswered question. Search linked sources or read the original page, attach an exact passage, and mark it reviewed only after checking the wording and conditions. New source revisions require another review; old evidence is retained. **Build decision brief** appends a table, recommendation, citations and open questions to the writing desk and saves a snapshot first. Export Word, Markdown or HTML from there. To preserve the entire project, export a JSON backup. For backups up to 2 MiB, **Copy backup text** and **Preferences & backups → Restore from backup text** provide a second route if downloads are unavailable. Save copied text to a separate file for durable backup.

**中文：** 在“新建项目”选择“方案比较与研究简报”，或先体验完整示例。填写目标、约束、方案及比较维度，在表头关联资料。打开单元格，记录事实、个人判断或待确认信息；检索关联资料或直接查看原文，附上准确引用，核对表述与条件后手动标记。资料出现新版本后需要再次核对，旧证据仍保留。“写入研究简报”会先保存快照，再把比较表、建议、引用和待确认事项追加到写作页。随后可导出 Word、Markdown 或 HTML。完整项目使用 JSON 备份；2 MiB 以内的备份还可以“复制备份文本”，在“偏好与备份 → 从备份文本恢复”中还原。请把复制的文本另存为文件，才能长期保留。

## Review a whole comparison / 连续核对

**English:** Link each option's sources, then select **Find evidence for all**. Open **Search terms** under a criterion to use a concrete phrase such as “pricing” or “CSV export”. Choose **Source updated**, **Not reviewed** or **To confirm**, then **Start review**. Check the saved quote against the current page. Use **Use current version & recheck** only after checking its conditions, or search for a replacement. Update your finding, tick the manual review checkbox, and **Save & next**. Cancel closes the current draft without saving it; previously saved findings remain. Build a new brief when the review is ready; earlier briefs remain snapshots.

**中文：** 关联资料后点击“批量找证据”；维度下的“检索词”可填写更具体的价格、导出等关键词。筛选“来源更新”“未核对”或“待确认”，点击“连续核对”。对照旧引用和当前原文，决定采用当前版本还是重新检索证据；编辑发现，人工勾选核对，然后“保存并继续”。取消只放弃当前未保存草稿，之前已保存的条目仍保留。核对完成后再生成新的简报，旧简报仍是之前的快照。

## English

1. If startup protection appears, choose **Open workspace safely**. Create a new project with **New project**.
2. Open **Your workflow → Collect**. Import a text-based PDF, Markdown or TXT file, or paste text. No account, API key or model is needed.
3. Open **Ask your sources**, choose a source scope and leave **Find passages** selected. Ask a specific question, such as “What is the annual budget?”. **Ctrl/⌘ + Enter** submits. Narrow the scope or try a clearer phrase if nothing is found.
4. Expand **Evidence ledger**. **Open source** retains the exact page and revision. PDF preview loads only when requested; close it to free resources. After reading, choose **Mark reviewed**. This records your own review, not a model's accuracy judgment.
5. Select a paragraph and choose **Add to document**. Open **Writing desk** to see the passage and its citation. **Undo insertion** works until the writing changes; **Version history** retains the earlier snapshot.
6. Choose **Export → Project backup**, then **Save file** in the ready notice. This second click saves the prepared file; the app cannot certify the browser saved it. Keep the file outside browser storage.
7. In **My workspace → Choose backup**, select the saved JSON. Restore creates a separate project and preserves writing, original files, revisions, research and review checkmarks.

**Optional AI:** select AI answer and manually enable it on a WebGPU device. The first download is large. Source passages are the evidence; check each generated claim. Use Cancel setup, Stop answering or Turn off AI when needed. Leaving/hiding the page releases AI.

## 简体中文

1. 如出现启动保护，选择“安全打开”。点击“新建项目”。
2. 从“项目指南 → 收集”导入文字型 PDF、Markdown、TXT，或粘贴资料；无需账号、API Key 或模型。
3. 打开“从资料中找到答案”，选择资料范围，使用“查找原文”。提出具体问题，例如“年度预算是多少？”，按 Ctrl/⌘ + Enter 提交。找不到时缩小范围或换一种更直接的问法。
4. 展开“证据清单”，点击“打开原文”核对页码和版本。PDF 预览按需打开，关闭后释放资源。读完后标记“我已核对”；这只记录个人核对，不是自动判定正确。
5. 勾选段落并“写入正文”，在写作页查看正文及引用。继续编辑前可“撤销写入”，之后仍可从“版本历史”恢复先前快照。
6. “导出 → 项目备份”准备文件，然后点击“保存文件”。生成成功不代表浏览器已保存，请保留实际下载文件。
7. “我的工作空间 → 选择备份”可恢复为独立新项目，保留正文、原文件、资料版本、问答和核对标记。

**可选 AI：** 需 WebGPU 和首次模型下载。请核对生成结论；可取消加载、停止回答或关闭 AI，离开/隐藏页面也会释放运行资源。
